# 使用说明

## 安装到手机桌面

Android Chrome 打开站点 → 右上角菜单 →「添加到主屏幕 / 安装应用」。之后从桌面图标进入，是全屏独立窗口，不显示地址栏。

iOS 也可以用 Safari 的「添加到主屏幕」，但离线行为不如 Android 稳定。

## 记录一次工时

1. 首页底部点 `+ 值班记录`。
2. 日期默认今天，要改就点日期。
3. 选地点：艺术中心 / 素拓。
4. 开始时间默认是**当前整点**（16:15 打开就是 16:00），结束时间自动算好。
5. 基础工时横向提供 1.5h、2h、2.5h、3h 四项，默认 2h。
6. 有加班就展开「加班时间」，填小时数（支持两位小数，上限 12）。
7. 点保存。

保存是即时的：点完就返回，不需要等网络。任何时候看到 `已保存到本机，联网后自动同步` 就说明数据已经落到手机上。

## 单独记录加班

不属于一次值班的小活儿，点首页底部的 `+ 加班记录`，或在日期详情里点同名按钮：

1. 日期默认今天；从日期详情进入则沿用当天日期。
2. 填写工作内容，例如「整理资料」「布置场地」，去除首尾空格后必填，最多 100 字，不需要填写地点。
3. 开始时间默认当前整点，加班时长默认 1 小时；可以修改开始、结束时间或时长。
4. 时长按小时输入，最多两位小数，换算成整数分钟后保存，范围为 1 分钟到 12 小时。
5. 保存后可以在日期详情中编辑或删除；记录类型不能在编辑时转换。

修改开始时间或时长会自动计算结束时间；修改结束时间会反算时长。跨午夜显示「次日」，计入开始那天；开始、结束相同不能保存。

## 选择日期与时间

点日期会打开应用内月历，周一为首列，左右箭头切换月份，「今天」定位并选中今天。点开始或结束时间打开 24 小时面板：先选小时，再选 `00 / 15 / 30 / 45` 分钟。

点「确定」才应用选择；点「取消」、关闭或按 Esc 返回原表单，保留原值。电脑上也可以用 Tab、方向键和回车操作选项。

小数时长计算或历史记录可能包含其他分钟，例如 0.1 小时对应 6 分钟。应用会原样保留，面板里也会保留当前的特殊分钟，不会自动取整。

## 看某一天的记录

点日历里的任意日期格子，底部弹出当天详情：

- 没有记录时显示「当天暂无工作记录」，可直接选择添加值班或加班记录。
- 有记录时按开始时间排序，每条显示地点、时段、基础与加班。
- 点某条记录进入编辑；标题变成「编辑记录」，按钮变成「保存修改」。
- 每条记录右侧有「删除」按钮，可在日期详情里直接删除；编辑页底部也保留「删除记录」。两个入口都需要确认，删除后自动更新当日合计、月度统计和日历颜色。

## 日历颜色

| 颜色 | 含义 |
|---|---|
| 白色 | 当天没有记录 |
| 浅蓝 | 只有艺术中心 |
| 浅绿 | 只有素拓 |
| 蓝绿渐变 | 两种地点都有 |
| 淡紫 | 只有独立加班 |
| 原值班底色＋紫点 | 当天还有独立加班 |

值班底色只看地点，不看条数和工时。值班记录里的附加加班不会触发紫色标记；紫色专指独立加班。今天会有一圈细蓝边。

顶部卡片左侧显示本月全部累计工时，右侧显示本月工资，下方保留值班与加班小计，不再显示记录天数。工资按全部累计工时（含附加加班及独立加班）× 25 元/小时计算，以「￥」显示并保留两位小数，月底累计分钟合计后再计算金额。值班小计只含基础工时；加班小计包含值班附加加班和独立加班。例如基础值班 2h、附加加班 0.5h、独立加班 1h，会显示总计 3.5h、值班 2h、加班 1.5h。

## 同步状态

标题下方小圆点旁的文案：

- `已同步`：本地和云端一致。
- `等待同步（N）`：有 N 条改动还没送出去，会自动重试。
- `离线中，记录已保存在本机`：没网，照常记录，联网后自动补。
- `同步失败，请在设置查看原因`：服务器或网络异常，数据仍在本地。
- `登录已失效，请重新登录`：会话过期（30 天），重新登录即可，本地数据不会丢。

## 设置菜单

右上角 `⋮`：

- **导出 CSV**：导出两类全部记录，Excel / WPS 直接打开不乱码。原有列后追加「记录类型」「工作内容」，独立加班的地点留空、基础工时为 0。
- **立即同步**：手动推一次、拉一次。
- **同步诊断**：失败时显示原因，可复制或下载诊断报告交给管理员；报告不含密码、Cookie 和工作内容。
- **从云端重建本机数据**：用服务器数据覆盖本地缓存，用于换设备或数据对不上。有未同步修改时会先提醒。
- **退出登录**：会清空本机数据。有未同步记录时会明确提醒，确认后才清。

## 换手机

旧手机：确认状态是「已同步」→ 新手机打开同一地址 → 登录 → 数据自动拉下来。
旧手机可以之后再退出登录。

## 关于时间和跨午夜

- 日期、开始时间都是你所在地的本地时间，服务器不换算时区。
- 23:00 开始、3 小时的记录，结束时间会显示 `次日 02:00`，这条记录仍然算在**开始那天**。
- 手改结束时间时如果算出的加班超过 12 小时，或者结束时间早于「开始 + 基础工时」，会阻止保存。
